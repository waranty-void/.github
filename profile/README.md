# Warranty Void

We’re an independent workshop for people who take things apart, build prototypes and share what worked. In Discord, you can pitch an idea, keep a build log or ask someone to test a prototype.

[Visit the project gallery](https://wvoid.coal.marketing/) · [How to contribute](https://wvoid.coal.marketing/community/)

## Count23

Pick a time and send the countdown to a friend. They can confirm it or suggest another time. The engineering guide explains how the shareable link holds the proposal.

[Run Count23](https://wvoid.coal.marketing/projects/count23/) · [Read the engineering notes](https://wvoid.coal.marketing/engineering/count23/) · [Browse the fork](https://github.com/waranty-void/count23)

Each public release has its own source and reuse terms. Coal Marketing provides our current web address and hosts the private Kanban. Warranty Void runs the projects.
